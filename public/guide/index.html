Guess the Counter-Strike pro player

CS Guess is an open-source guessing game for Counter-Strike esports fans. Submit a player name and use the comparison clues to narrow down the mystery player. It is inspired by BLAST Counter-Strikle.

Play CS Guess

How to play

  1. Open the game and choose a player identity. The game restores your existing identity in the same browser.
  2. Pick a mode, search for a professional player, and submit a guess.
  3. Compare the clues with your guess. Use matches and numerical hints to choose your next player.
  4. Keep narrowing down the candidates until you find the answer or the round ends.

What the clues mean

Clues compare team, nationality, age, playing role, Major appearances and Major wins. A numerical hint helps you decide whether to look for a higher or lower value. The exact information visible can depend on the selected mode and settings.

Player data comes from a maintained catalog. Rosters and player statistics can change, so use the game's displayed data and update time when interpreting a clue.

Choose your mode

  • Daily challenge: a shared daily puzzle to return to and compare results.
  • Solo practice: practice at different difficulty levels.
  • Matchmaking: enter a real-time match with other players.
  • Private rooms: create a room or join with a room code to play with friends.

Before starting

The game requires JavaScript and an internet connection. English and Simplified Chinese are available from the language switcher.

Source code and feedback

Read the CS Guess source on GitHub or report a problem. If you enjoy the game, a Star helps other Counter-Strike fans find the project.
