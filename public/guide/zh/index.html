根据线索，猜出 CS 职业选手

CS Guess 是面向 Counter-Strike 电竞爱好者的开源猜谜游戏，灵感来自 BLAST Counter-Strikle。提交一位选手的名字，对照反馈线索逐步缩小范围，找出本轮的神秘选手。

开始游戏

怎么玩

  1. 打开游戏并选择玩家身份。在同一浏览器再次访问时，游戏会恢复已有身份。
  2. 选择模式，搜索一位职业选手并提交猜测。
  3. 对照战队、国籍等线索，结合数值提示选择下一位候选选手。
  4. 继续排除不符合条件的候选人，直到猜中或本轮结束。

有哪些线索

游戏会比较战队、国籍、年龄、位置、Major 参赛次数和 Major 冠军次数。数值提示帮助你判断应该寻找更高还是更低的值；具体可见信息与所选模式和设置有关。

选手信息来自维护中的数据目录。战队阵容和统计数据会变化，判断时请以游戏显示的信息和数据更新时间为准。

选择适合你的模式

  • 每日挑战：每天一道共同题目，适合持续挑战和比较成绩。
  • 单人练习：按不同难度练习，熟悉选手资料和线索。
  • 实时匹配：与其他玩家进入实时对局。
  • 好友房间：创建房间或输入房间号，与朋友一起玩。

开始前需要什么

游戏需要启用 JavaScript 并连接网络，界面支持中文和英文，可通过语言切换按钮选择。

源码与反馈

在 GitHub 查看 CS Guess 源码，或反馈问题。如果玩得开心，也可以点一个 Star，让更多 CS 玩家发现这个项目。
